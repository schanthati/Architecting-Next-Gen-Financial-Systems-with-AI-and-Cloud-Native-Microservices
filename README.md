## Description

This conference proceeding presents frameworks for designing financial systems combining AI models and cloud-native microservices. The work includes reference architectures integrating Large Language Models (LLMs), vector databases, Kafka-based real-time ingestion, and zero-trust security patterns.

Use cases include revenue automation, AML surveillance, ESG scoring, and investment operations optimization. The proceeding also discusses LLM-powered components embedded into microservices using frameworks such as LangChain and Kubernetes, real-time data federation through Kafka streams and vector embeddings, workflow automation using ServiceNow integrated with AI decision engines, and compliance enforcement using containerized audit logs and policy-as-code mechanisms.
